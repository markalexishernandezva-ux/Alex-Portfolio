# Alex Hernandez · Virtual Executive Assistant (portfolio)

A single-page portfolio for GitHub Pages. No build step.

## 1. Add your contact details (required)
Your email and LinkedIn are already set. To change them, edit `index.html`:
- `YOUR_EMAIL@example.com` (appears in the `EMAIL` setting near the bottom and in the "Email me" button)
- `YOUR-LINKEDIN` in the LinkedIn button

## 2. Publish on GitHub Pages
1. Create a repo named `yourusername.github.io` (or any name).
2. Upload everything in this folder: `index.html`, `photo.png`, `assets/`, `.nojekyll`, `README.md`.
3. Settings → Pages → Source: "Deploy from a branch" → `main` / root → Save.
4. Your site goes live at `https://yourusername.github.io` in a minute or two.

## 3. Privacy check before going public
The screenshots in `assets/` were cropped to show only dashboards and totals. Lead-generation contact lists
(names, companies, emails) were left out on purpose. Before adding new screenshots, blur or replace any real
names, emails, or client data.

## 4. Swap or add images
Each project card loads `assets/<name>.jpg`. Replace a file with the same name to update it.

## 5. Switch on the optional features
Open `index.html`, find the block near the bottom that says "Optional integrations", and fill in one or more:

- `FORMSPREE_ID`: Sign up free at formspree.io, create a form that sends to markalexishernandez.va@gmail.com,
  and paste the form ID (the part after `/f/`). Until then, the contact form opens the visitor's email app instead.
- `BOOKING_URL`: Paste your Calendly or Google Calendar booking link. A "Book a call" button appears and the
  "Book an intro call" and "Hire Alex" buttons switch to it.
- `GOATCOUNTER_CODE`: Sign up free at goatcounter.com and paste your site code (the part before `.goatcounter.com`).
  It counts visits plus clicks on Email, LinkedIn, Book a call, and form sends, without cookies.

Any field left empty stays switched off, and the site still works.
